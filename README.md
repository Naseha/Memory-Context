## What this repository contains
This is the first public release of a two-part case study:
1. **Memory Context Protect** (`1-memory-context-protect-v1.1.md`)  
   A structured way to create lean “load-bearing” summaries so important facts, relationships, and emotional continuity survive long threads.
2. **Calculate and Match Empathy** (`2-calculate-match-empathy-score-v1-0.md`)  
   A method to calculate a user’s Empathy Score using Cognitive, Affective, Relational, Environmental, and Noise parameters, and then require the agent to match that score in its responses.
Together they form a practical approach to reducing both context loss and relational friction in long conversations.

## Why it exists
In long conversations (especially creative, multi-day, or high-stakes threads), two problems appear repeatedly:
- Models forget earlier important details
- Models fail to match the user’s actual communication style and emotional stance
This repository offers lightweight, practical methods to address both.
